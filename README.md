# 🎯 秋招求职 SOP 工作台（qiuzhao-workbench）

面向 **2027 届秋招大学生**的一站式求职 SOP 个人工作台。单文件 HTML 交付，浏览器打开即用，数据保存在浏览器本地（localStorage），无需服务器、零依赖、离线可用。

> 在线演示：https://3bb40a1c10c547c79ea5c9033e271f2d.app.workbuddy.link
> （每位访问者的数据只存在自己的浏览器里，互不可见）

---

## ✨ 四大核心功能

| 模块 | 说明 |
|---|---|
| 📄 **简历智能优化** | 基本信息 / 实习 / 项目 / 其他四段式填写；粘贴目标岗位 JD 一键「对齐分析」，自动扫描 JD 关键词在简历中的覆盖率，逐条给出 **STAR 法则 + 量化**改写建议，可一键采纳；右侧实时生成 **1 页 A4 简历预览**（自动字号缩放），支持导出 Word 版 |
| 🎤 **面试准备生成** | 基于「简历 + JD」自动生成 4 组高频面试题与参考回答：自我介绍/动机 → JD 技能深挖 → 简历深挖 → 行为题（STAR）；支持导出 Word 版题库 |
| 🕘 **简历版本管理** | 每次优化一键「保存为新版本」，按投递公司/岗位命名；历史版本回看 + **LCS 行级 diff 左右对比**（红=删除 / 绿=新增）；支持版本备份导入导出 |
| 📊 **秋招投递进度看板** | 记录 公司/岗位/批次/城市/渠道/日期/链接/备注；8 状态流转：待投递→已投递→一面→二面→终面→Offer / 拒信 / 流程终止；顶部漏斗 + 统计卡一屏看全局 |
| 🗂 **企业信息池** | 内置 **1082 家** 2027 秋招企业（提前批+正式批），支持按行业 / 批次 / 城市筛选、关键词搜索、分页浏览、一键「去投递」 |

### 体验细节
- **「今天要处理」置顶**：逾期未投递标红 + 一键推进，昨天没做完的自动顺延到今天
- 预置示例数据（含逾期样本），首屏不空白；可一键清空
- 数据 ≥30 条自动温和提醒「导出备份」
- 「导出 JSON 备份 / 导入恢复」一键完成；清空数据需二次确认
- PC 双栏 + 移动端单列自适应，可添加到手机桌面当 App 用

## 🏗 技术架构

- **纯前端单文件**：`index.html` 内含全部 CSS / JS / 内联 SVG 图标，**零外部依赖**（无 CDN、无字体、无框架）
- **数据持久化**：浏览器 `localStorage`，key 前缀 `wb_qz_`
- **Word 导出**：纯 JS 手写 **ZIP(STORE) + OOXML** 实现 `.docx` 生成（`crc32`、ZIP local/central/EOCD 结构），无需任何库
- **代码架构**：`WB` 核心库（数据/计算/DOCX，无 DOM 依赖，可独立测试）与 UI 层分离；渲染函数相互独立，由唯一入口 `refreshAll()` 统一刷新（有向无环调用链，杜绝递归环）
- **离线规则引擎**：JD 关键词词库提取 → 简历覆盖扫描 → STAR 量化分析 → 逐条优化建议
- **信息池内联**：清洗后的企业数据直接内联为 `window.POOL_DATA`（1082 行紧凑数组），规避浏览器 file:// 协议下 fetch 本地文件的限制

## 🔒 隐私说明

- 简历、JD、面试题、投递记录等**用户业务数据只存于浏览器本地**，不上传任何服务器
- `index.html` 中不含任何个人真实简历内容，仅含示例数据与公开招聘信息
- 部署为在线链接后**任何人拿到链接都能打开**，请勿在公开页面预填真实敏感数据

## ⚙️ 本地使用

双击 `index.html` 用浏览器打开即可，无需安装。数据备份/恢复均在页面右上角。
